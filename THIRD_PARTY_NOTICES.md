# Avisos de terceros

Generado por `python scripts/third_party.py` a partir de `Cargo.lock`, `ui/package-lock.json` y el inventario del propio script (D60). No lo edite a mano. Las licencias son las que declara cada componente; no es una revisión legal. El instalador lleva además el texto completo de cada licencia (`THIRD_PARTY_NOTICES.txt`).
